# Guess 前后端升级 + 后端优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 前后端依赖升级到安全小版本，后端手工借鉴 code-kit 优化（不引入 code-kit 依赖）。

**Architecture:** 只改版本号与本仓源码；code-kit 仅作思路参考（复制思想、手写代码，不加 submodule/依赖）。

**Tech Stack:** Spring Boot 3.5 + Java 25 + Gradle；前端 npm + webpack 小程序。

**Spec:** 本文件即 spec。code-kit 参考源：`/Users/jingan/workspace/code-kit`（只读）。

## Global Constraints

- 不引入 code-kit（无 submodule、无新 Maven/npm 依赖指向 kit）。
- 不做大版本跳跃：Boot 3.4→3.5（不做 4.x），Flyway 不做 12/13，mysql 用 9.x（不用 26.x 年号版），前端不动 tailwind/mobx/jest/webpb 大版本。
- 每次改动后可构建验证；测试需 docker（testcontainers），若环境无 docker 则至少保证编译通过并注明。
- conventional commits（commitlint：scope 仅 deps/frontend/lib/service）。

## Review Focus

- webpb 0.0.16→0.0.42 后必须全量重生成 proto（java+ts），旧生成代码 + 新 runtime 混用不在测试矩阵内。
- testcontainers 2.x 坐标与包名全变，漏改一处即编译失败。
- mysql 8.0.33→9.7.0：驱动类名不变，但连接行为/时区默认需回归测试覆盖。
- 删除 authorization-server 后 oauth2 resource 类由 starter-oauth2-resource-server 补齐，漏换即编译失败。
- 前端 package-lock 必须与 package.json 同步更新并跑通 lint/test。
